# Village Economy Mod

Track and manage village economies in Minecraft.

## Features

- Check village economy levels with the `/villageeconomy` command
- Locate villages by level with the `/locatevillage` command

## Requirements

- Minecraft 1.21
- Forge 49.0.30 or later

## Installation

1. Download the mod file
2. Place it in your `mods` folder
3. Launch Minecraft with Forge

## Usage

### Commands

- `/villageeconomy <level>` - Check the economy level of a village (1-5)
- `/locatevillage <level>` - Locate a village by its economy level (1-5)

## Configuration

The mod does not require any configuration files.
